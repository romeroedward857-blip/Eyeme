ANOMALY SCANNER V2.4 — GITHUB ACTIONS

1. Crea un repositorio nuevo en GitHub.
2. Sube TODO el contenido de esta carpeta, incluido .github.
3. Abre Actions.
4. Selecciona "Build Anomaly Scanner APK".
5. Pulsa "Run workflow".
6. Espera a que termine.
7. En la ejecución terminada, descarga el Artifact:
   anomaly-scanner-v2.4-apk

El APK estará dentro del archivo descargado.

main.py es el punto de entrada de Android.
icon.png es el icono 512x512.
presplash.png es la pantalla de inicio.

La primera compilación puede tardar porque Buildozer prepara las herramientas Android.
